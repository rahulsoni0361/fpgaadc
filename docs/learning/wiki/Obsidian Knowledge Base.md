# Obsidian Knowledge Base

The **Obsidian Knowledge Base** architecture organizes technical documentation into an interconnected, bidirectional graph of Markdown documents.

## Architectural Rules

1. **Double-Bracket Wiki Links**: Concepts are encapsulated in `[[concept]]` syntax.
2. **Deterministic File Placement**: Stubs reside in a dedicated `wiki/` subdirectory.
3. **Mandatory Backlinks**: Every spawned note contains an opening and closing backlink to its parent document (`[[live-dsp-browser-pipeline]]`).
4. **Context Injection**: Every stub begins with a Context statement to preserve semantic clarity when accessed out of context.
5. **Solarized Theme & Bracket-Wrap Plugin**: Pre-configured in `.obsidian/` for seamless visual hierarchy and hotkey wrapping (`Ctrl+Shift+F16`).
