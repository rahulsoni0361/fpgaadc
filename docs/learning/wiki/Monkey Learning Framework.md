# Monkey Learning Framework

The **Monkey Learning Framework** is a four-step cognitive methodology designed to eliminate the "Familiarity Trap" — the psychological illusion where passive reading feels like comprehension but yields zero long-term retention.

## The 4 Steps

1. **Step 1: Mission Question**:
   Before diving into code or theory, establish a central question:
   > *"When I close this resource, what is one question I want to be able to answer without looking?"*

2. **Step 2: Closed-Book Retrieval Test**:
   Close the document immediately after learning a concept and answer:
   - How would I explain this simply?
   - What is one concrete example or connection?
   - What is still unclear?

3. **Step 3: Make One Idea 'Pay Rent' (Transfer)**:
   Apply the knowledge to a physical or code action within 24 hours (e.g. modifying an FPGA template or touching a physical ADC probe).

4. **Step 4: The Cooling Gap (Spaced Repetition)**:
   Test recall after 24 hours (next day) and 7 days (next week) to force retrieval from long-term memory.
